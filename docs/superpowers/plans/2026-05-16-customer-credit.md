# Customer Credit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build native iPad customer accounts with tenant-wide credit limits, partial credit purchases, account payments, ledger history, refunds, receipts, and credit-aware reports.

**Architecture:** Add a bounded customers domain with a DataStore-backed customer slice and credit ledger service. Sales owns customer selection and payment UI; orders owns order close/refund lifecycle and calls customer services for credit ledger entries; reporting and printing consume order and ledger data without owning credit rules.

**Tech Stack:** Nx, React Native, Redux Toolkit, AWS Amplify DataStore, Jest, existing shared UI/native components, existing printing and reporting services.

---

## Scope And PR Strategy

This feature crosses schema, data access, sales UI, orders, printing, and reporting. Execute it as one ordered implementation sequence, with frequent commits and a final implementation PR. Each execution session must start from latest `main`. The final PR description must include the manual test checklist at the end of this plan.

- [ ] **Step 2: Implement pure customer credit helpers**

Create `customer-credit.logic.ts` with:

```ts
export type CustomerCreditStatusValue = 'OK' | 'OVER_LIMIT';

export interface CustomerCreditSnapshot {
    active: boolean;
    creditLimit: number;
    creditBalance: number;
}

export const roundMoney = (value: number) =>
    Math.round(((Number(value) || 0) + Number.EPSILON) * 100) / 100;

export const getAvailableCredit = (customer: Pick<CustomerCreditSnapshot, 'creditLimit' | 'creditBalance'>) =>
    roundMoney(Number(customer.creditLimit || 0) - Number(customer.creditBalance || 0));

export const getCreditStatus = (customer: Pick<CustomerCreditSnapshot, 'creditLimit' | 'creditBalance'>): CustomerCreditStatusValue =>
    Number(customer.creditBalance || 0) > Number(customer.creditLimit || 0) ? 'OVER_LIMIT' : 'OK';

export const canUseCustomerCredit = (customer: CustomerCreditSnapshot | undefined, amount: number) => {
    if (!customer) return { allowed: false as const, reason: 'NO_CUSTOMER' as const };
    if (!customer.active) return { allowed: false as const, reason: 'INACTIVE_CUSTOMER' as const };
    const requested = roundMoney(amount);
    if (requested <= 0) return { allowed: false as const, reason: 'INVALID_AMOUNT' as const };
    if (getAvailableCredit(customer) < requested) {
        return { allowed: false as const, reason: 'INSUFFICIENT_CREDIT' as const };
    }
    return { allowed: true as const };
};

export const normalizeContactValue = (value?: string | null) =>
    String(value || '').trim().toLowerCase();

export const buildCustomerDuplicateError = ({
    phoneExists,
    emailExists,
}: {
    phoneExists: boolean;
    emailExists: boolean;
}) => {
    if (phoneExists) return 'Phone is already assigned to another customer.';
    if (emailExists) return 'Email is already assigned to another customer.';
    return undefined;
};
```
